# Vertical 12: Meta-Game

The systems around the levels that bring players back each day and keep them playing after the campaign: dispatches, weekly goals, collections, achievements, cosmetics, and the endgame.

## Principles

- **Every reward is earned by typing** (P1, P5). No rewards for simply logging in.
- **No punishment for absence** (P6). No daily streak that resets. Missed dispatches expire quietly.
- **No dark patterns.** No loot boxes, no purchases, no countdown pressure beyond a daily refresh, no guilt messages.
- **Short-term, mid-term, long-term goals at all times.** There's always something to finish this session, this week, and this month.

## Reward cadence

| Horizon | What the player is working toward |
|---|---|
| This level | Stars, medals, a new best |
| This session | Today's flight plan, three dispatches |
| This week | Weekly goal, a Keyling's next mastery state |
| This zone | Gate stars, boss, new machine, new Keylings |
| The campaign | Ranks, every Keyling, the Silent Core |
| After the campaign | Ace tiers, speed badges, the Deep Archive, Courier records |

## Dispatches (daily quests)

Three short orders from Commander Okafor each day, refreshed at local midnight.

### Rules

- Each dispatch is a typing task achievable within a normal 15–20 minute session.
- At least one of the three fits naturally into today's flight plan.
- Unfinished dispatches expire at refresh with no penalty and no message.
- Completing a dispatch awards **commendations** (see Commendation track).

### Templates

| Dispatch | Example target |
|---|---|
| Earn medals | Earn 2 medals |
| Earn stars | Earn 3 stars |
| Clean runs | Finish 3 levels at 95% Integrity or better |
| Characters | Type 600 correct characters |
| Signal lock | Reach ×6 Signal lock |
| Overdrive | Trigger Overdrive 3 times |
| Repair | Complete a repair run |
| Beacons | Rescue 5 stranded beacons |
| New best | Set a new best on any level |
| Look back | Replay a level from an earlier zone |
| Rhythm | Earn Steady Hand on any level |
| Focus key | Type 50 correct G's (uses the player's weakest key) |
| Twin Suns | Type 30 capitals with the opposite-hand Shift (Zone 5+) |
| Numbers | Clear a coordinate-lock level (Zone 7+) |

Targets scale with the player's zone so they stay achievable.

## Weekly goal

- **Practice on 4 of the last 7 days.** The week is a rolling window, not a calendar week, so there's no Monday reset.
- Progress shown as seven small lights on the hub; days practiced light up.
- Completing the weekly goal awards commendations and, the first few times, a cosmetic.
- Falling short has no consequence. Lights roll off as days pass.

It rewards regular practice (the spacing effect) without making a missed day feel like a loss.

## Commendation track

A long, fixed sequence of cosmetic rewards filled by commendations from dispatches and weekly goals.

- Commendations are not spendable; they only fill the track.
- The order is fixed and visible, so players know what's next.
- About 40 steps over the campaign, then an endless repeating tier of minor rewards (ship trail colors, Dash accessories).

| Steps | Example rewards |
|---|---|
| 1–10 | Ship paints, Dash's first hat, hub banners |
| 11–20 | Engine trails, Dash accessories, station lights |
| 21–30 | Animated paints, Keyling poses, hub decorations |
| 31–40 | Rare trails, a unique Dash outfit, a title |

## Collections

### Keylings

The main collection. One Keyling per key, rescued as each key is learned.

| Group | Keylings |
|---|---|
| Letters | 26 |
| Space | 1 |
| Punctuation | , . / ; ' ? |
| Shift | 2 (left and right, twins) |
| Numbers | 10 |
| Symbols | - : ! " ( ) @ # $ % & |
| Editing | Backspace, Enter, Tab |

- Each Keyling shows its mastery state (new, learning, solid, mastered).
- **Variants:** rare alternate looks earned through Keyling Rescue side levels and Ace tiers (for example, a crystal F from the High Spires).
- The Keyling roster is a page in the Dossier and a wall in the hub.

### Codex

Story entries for sectors, characters, Keylings, Wardens, and machines. Unlocked through the story, bosses, and exploration (side levels).

### Cosmetics

| Category | Examples | Earned by |
|---|---|---|
| Ship paints | Ember, Spire crystal, Undertow glow | Commendation track, achievements |
| Engine trails | Letter trail, star trail, river trail | Commendation track, speed badges |
| Dash accessories | Hats, antennae, tiny scarves | Commendation track, weekly goals |
| Hub decorations | Banners, lights, plants, Keyling perches | Zone clears, ranks |
| Titles | "Beacon Finder," "Undertow Diver," "Signal Ace" | Achievements, ranks |

## Endgame

What keeps players typing after the Hush is defeated. Most of it unlocks progressively during the campaign.

| Mode | Unlocks | Description |
|---|---|---|
| **Ace tiers** | Per level, via medals | Harder versions of every level with their own stars |
| **Courier runs** | Zone 6 | Timed runs (1, 3, and 5 minutes) on original prose. The game's version of a typing test. Personal records and speed badges. |
| **Ghost races** | Zone 6 | Race a ghost ship replaying your own best Courier run, keystroke by keystroke |
| **The Deep Archive** | After the Hush | Endless convergence mode; messages from the Archivist. Pace rises steadily; the run ends when the shield is depleted (the only mode with an end-by-damage rule). Best distance recorded. |
| **Daily Signal** | After the Hush | One generated challenge per day, the same for every player, scored for personal bests |
| **Boss rush** | After the Hush | All nine Wardens back to back |
| **Glyph Vaults** | Zone 8 | Rare-symbol side levels |

## Hub growth

The station visibly changes as the player progresses:

| Trigger | Change |
|---|---|
| Each zone cleared | New docking lights, a new docked ship, a crew member silhouette |
| Each Keyling rescued | Appears on the Keyling wall |
| Each rank | Cadet's quarters grow |
| Weekly goals | Small decorations |
| Hush defeated | The whole station blazes with every zone's color |

## Not now
